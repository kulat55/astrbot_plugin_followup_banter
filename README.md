# astrbot_plugin_followup_banter

AstrBot 追问补刀插件：虚拟人格在私聊中被用户吐槽、回怼之后，偶尔追加一条追问，让斗嘴更像真人。

## 场景示例

```
用户: 肥猪啊
林小瞒: 你才是肥猪，我这是正常吃饭
（隔 1-3 秒追加）: 你不吃的比我多！
```

## 触发条件

1. 用户消息含吐槽/调侃词：胖、肥、猪、傻、笨、蠢、菜、弱、懒、丑、矮、穷、抠、装、秀、离谱、虚胖、肥猪
2. 助手回复含反驳特征：才是、才不、我这是、正常、胡说、哪有、谁说的、明明、本来就是、凭啥、你才、才怪、才没有
3. 概率约 15%（10 次对话触发 1-2 次），只在私聊生效

追问会在助手回复发送完成后再隔 1-3 秒发出，模拟真人"补刀"。

## 安装

AstrBot 插件市场上传 zip 安装，或将整个目录放入 `core/data/plugins/` 后重启。

## 配置

无配置项。调节触发概率：修改 `main.py` 中 `random.random() >= 0.15` 的数值（0.1 = 约 10 次触发 1 次）。

## 依赖

无（纯 AstrBot API + 标准库）。
